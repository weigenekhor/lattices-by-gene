# LATTICES website instructions

Read `README.md` before substantial frontend work. It describes the current website, source data and verification commands.

- The latest user prompt takes precedence.
- Read actual desktop source before changing product names, geometry, grouping or controls.
- Keep canonical app facts, screenshot ownership and featured status in `content/apps.json`.
- The hero contains one native product window, defaulting to Pentimento edition and Tenebrismo appearance. Mode (Legacy/Pentimento) and visual theme (Imprimatura/Tenebrismo/Pentimento) are independent controls in `state.js`; all 20 applications stay represented. The surrounding website palette stays graphite.
- Home surfaces, icons, card geometry and information panels come from the actual desktop renderer. Typography is live browser text for display-density sharpness. Hover/focus shows native information; clicking a card or sidebar app opens its source-exported, unpopulated desktop layout. The latest user request removes all demo behavior. Do not add sample results, fabricated layouts, application screenshot layers or processing actions.
- Preserve changes in Git before replacing them. Do not modify source captures or desktop code.
- Build, run relevant checks and inspect rendered output before claiming visual work complete.
